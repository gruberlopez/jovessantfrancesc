# Joves Sant Francesc
Static landing page in Catalan (default), Spanish, and English. Content and contact details are based on `assets/Cartelgrupo.pdf`; photographs and brand palette are supplied by the group.

Preview locally: `python3 -m http.server 8000 --directory dist` from this directory, then open http://localhost:8000.

Language-specific links: `?lang=es` and `?lang=en`. The default URL always opens in Catalan.
